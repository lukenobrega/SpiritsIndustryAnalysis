# SpiritsIndustryAnalysis
Used Python Pandas to visualize spirits industry datasets to create analysis and executive presentation.

This project was done during my past summer internship with Disaronno International USA. I was given 3 Excel files containing over 100,000 rows of data each. These files contained data of both U.S. and global data both value and volume metrics of many categories of spirits. Each dataset contained past recorded data as well as forecasted data. I then used Python Pandas and NumPy to clean the data and use the relevant columns, which I then visualized through many different graphs. Because of the sensitive nature of the data, I am not able to provide the datasets or the values on the graphs and report. I will provide the code used as well as a limited amount of the presentation. The results of this project were sent to the CEO of Disaronno International USA who then sent it to the CEO of the parent company, who made a LinkedIn post based on my findings.
